Rethinking Structured Generation: Can Graph-Based Reasoning Resolve Ambiguity?

Can a model produce more reliable structured outputs by considering multiple plausible interpretations instead of assuming only one answer is correct?

Ratun Rahman & Atit PokharelNeurIPS 2026 · AcceptedLLMs / NLP / Graph Reasoning

Research problem

Many structured-generation systems map a natural language input to exactly one target structure. Real language does not always work that way: two distinct structures may be semantically valid for the same underspecified request. Training solely against one reference risks suppressing alternatives and producing unstable outputs.

Approach

We frame structured generation as ambiguity-aware inference rather than single-output prediction. The method creates a set of plausible outputs, expresses each as a graph of entities and relationships, and reasons across these candidates using semantic alignment and relational consistency. It is designed to compare competing interpretations beyond token-level likelihood.

What the evaluation examines

  • Accuracy on structured generation benchmarks
  • Output stability when input wording or ambiguity changes
  • Robustness when more than one interpretation is defensible

The paper reports improvements in accuracy, stability, and robustness under varying ambiguity levels. For exact experiments, quantitative comparisons, and implementation details, refer to the paper.
